🖥️ Requisitos Mínimos del Sistema

  • Sistema Operativo: Windows 10 / 11 (64-bit).
  • Memoria RAM: Mínimo 4 GB (Recomendado 6-8 GB para mods).
  • Java: Runtimes integrados de OpenJDK (Java 8, 17 y 21 auto-configurados).
  • Almacenamiento: 150 MB para el instalador (Espacio libre para Minecraft).

🗑️ Instrucciones de Desinstalación Sencilla

Nebula Launcher no incluye software publicitario empaquetado y se puede remover por completo en cualquier momento:

  1. Abre Configuración de Windows > Aplicaciones > Aplicaciones instaladas.
  2. Busca Nebula Launcher en la lista y haz clic en Desinstalar.
  3. Sigue el asistente de desinstalación de Windows para borrar los binarios de tu PC.
