🖥️ Requisitos e instalación

  • Sistema Operativo: Windows 10 / 11 (64-bit).
  • Memoria, Java y espacio: consulta las notas de instalación y la sección de requisitos de la release elegida antes de instalar.

🗑️ Instrucciones de Desinstalación Sencilla

Para desinstalar Nebula Launcher, utiliza el desinstalador incluido o la sección de aplicaciones de Windows. La ubicación de datos de usuario puede ser distinta de la carpeta del programa: consulta las notas antes de borrarla.

  1. Abre Configuración de Windows > Aplicaciones > Aplicaciones instaladas.
  2. Busca Nebula Launcher y selecciona Desinstalar.
  3. Antes de eliminar manualmente datos de usuario, guarda los perfiles o mundos que quieras conservar.
