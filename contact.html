Preguntas Frecuentes (FAQ)

¿Nebula Launcher es compatible con cuentas de Microsoft?
Consulta la documentación de la release que estás usando para conocer las opciones de cuenta disponibles y los permisos que solicita el flujo de autenticación.
¿Qué debo hacer si Minecraft no inicia o sale "Exit Code 1"?
Exit Code 1 es un resultado genérico. Revisa el registro, las versiones recientes de Java, el cargador y los mods; nuestra guía de diagnóstico explica por dónde empezar.
¿Dónde puedo consultar el código y las versiones?
Revisa el repositorio de GitHub y sus releases. La publicación del código no sustituye una auditoría de seguridad independiente; verifica el origen de cualquier archivo que descargues.
¿Cómo instalo Modpacks de CurseForge o Modrinth?
La interfaz y las opciones de importación pueden variar entre versiones. Comprueba que el modpack, el cargador, la versión de Minecraft y las dependencias coincidan antes de instalar; consulta las notas de la release si tienes dudas.
