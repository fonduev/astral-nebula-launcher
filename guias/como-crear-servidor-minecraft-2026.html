🌐 Servidores & Red

Cómo Crear un Servidor de Minecraft en 2026: Guía Completa de Paper, Purpur y Java

✍️ fondue_x (Nebula Lab)
📅 Revisado el 12 de octubre de 2026
⏱️ 12 min de lectura

Puedes alojar un servidor Java para jugar en una red local o con invitados remotos. Los pasos dependen de la versión de Minecraft y del software elegido. Esta guía se centra en preparar una carpeta, iniciar un servidor Paper o Purpur, aceptar el EULA y revisar el acceso de red; no promete una capacidad de jugadores ni una mejora de rendimiento.

1. Escoge el software según los mods o plugins que necesitas

El servidor Vanilla distribuido por Mojang sirve para un mundo sin plugins de Bukkit/Paper. Paper y Purpur ofrecen compatibilidad con plugins de ese ecosistema, mientras que un servidor Fabric carga mods compatibles con Fabric. Cada opción puede cambiar comportamientos o requisitos: confirma que tus jugadores usan el mismo software, versión del juego y conjunto de mods/plugins. Ninguna opción es siempre la más rápida para todos los mundos y cargas.

Servidor Complementos habituales Comprueba antes de elegir
Vanilla Datapacks y funciones incluidas en el juego. La versión del server.jar debe coincidir con la de los jugadores.
Paper Plugins compatibles con Bukkit, Spigot o Paper. Revisa si un plugin requiere una API o build específica.
Purpur Plugins compatibles con Paper y opciones de configuración propias. Confirma el comportamiento esperado y la compatibilidad de cada plugin.
Fabric Mods publicados para Fabric, en servidor y cliente cuando corresponda. Instala las dependencias requeridas y alinea versiones con todos los jugadores.

2. Requisitos Previos de Software y Java

La versión de Java necesaria depende de la versión exacta del servidor. Comprueba el requisito actual en la documentación de Paper o Purpur y usa una distribución de Java de 64 bits compatible con tu sistema. El comando java -version muestra qué runtime ejecuta la terminal.

# Verificar versión de Java instalada en tu terminal java -version # Debe devolver algo similar a: # openjdk version "21.0.3" 2024-04-16 LTS # OpenJDK Runtime Environment Temurin-21.0.3+9 (build 21.0.3+9-LTS)

3. Estructura de Archivos y Script de Arranque (run.bat)

Crea una carpeta dedicada (por ejemplo, C:\MinecraftServer) y coloca allí el archivo JAR de Purpur o Paper renombrado a server.jar. Nunca ejecutes el servidor con doble clic; crea un archivo de texto llamado iniciar.bat con los parámetros adecuados de asignación de memoria:

@echo off title Servidor Minecraft java -Xms2G -Xmx2G -jar server.jar --nogui pause

Al iniciarlo por primera vez, el servidor se detendrá solicitando aceptar el EULA. Abre el archivo generado eula.txt y cambia la línea a:

eula=true

4. Apertura de Puertos (Port Forwarding) y Red

Para que personas fuera de tu red local puedan conectarse, debes abrir el puerto predeterminado 25565 TCP/UDP en el panel de administración de tu router apuntando hacia la IP local estática de tu ordenador (por ejemplo, 192.168.1.50).

⚠️ Consejo de Seguridad: Si no dispones de acceso al router o tu proveedor de internet utiliza CGNAT (Carrier Grade NAT), la solución más limpia y segura sin compartir tu IP pública es utilizar herramientas modernas como Playit.gg o túneles Cloudflare, evitando programas obsoletos como Hamachi.

5. Verifica el arranque y deja el servidor cerrado hasta revisar la red

  1. Inicia el servidor por primera vez desde la carpeta de instalación y espera a que genere sus archivos. Luego apágalo con stop en la consola.
  2. Lee el EULA incluido, y solo si aceptas sus condiciones cambia eula=false a eula=true. Vuelve a iniciar y comprueba que el mundo termina de cargar.
  3. Prueba primero desde la misma red local. Para acceso remoto, consulta la documentación de tu router y proveedor; expón solo el servicio requerido, usa una lista de permitidos si procede y mantén copias de seguridad.
  4. Instala plugins únicamente desde los canales oficiales de sus autores. Añade uno a la vez, revisa la versión compatible y conserva los registros si el servidor no inicia.

La RAM de ejemplo del archivo por lotes no es un requisito: ajusta -Xms y -Xmx al software, la carga y la memoria física disponible, dejando recursos para el sistema operativo.

Consulta las guías oficiales de Paper, Purpur y Spark; sus instrucciones pueden cambiar entre versiones.
